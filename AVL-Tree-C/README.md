# AVL木のC言語実装

## 概要

AVL木（自己平衡二分探索木）をC言語で実装したプログラムです。

AVL木は、挿入や削除によって木の高さが大きく偏らないよう、自動的に回転処理を行う二分探索木です。これにより、探索・挿入・削除を効率よく行うことができます。

## 主な機能

* AVL木の実装
* 再帰を用いた挿入処理
* 高さの管理
* 平衡係数の計算
* LL回転
* RR回転
* LR回転
* RL回転
* 中順巡回によるデータ出力

## 使用技術

* C言語
* ポインタ
* 動的メモリ確保（malloc）
* 再帰処理
* 木構造データ構造
* 自己平衡アルゴリズム

## コンパイル方法

```bash
gcc main.c avl.c -o avl
```

## 実行方法

```bash
./avl
```

## 実行例

入力データ

```text
10 20 30 40 50 25
```

出力

```text
10 20 25 30 40 50
```

## ファイル構成

* `main.c` : 動作確認用プログラム
* `avl.c` : AVL木の実装
* `avl.h` : 構造体定義および関数宣言
